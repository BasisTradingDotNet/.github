# .github

BTNET Quantitative — organization profile ([profile/README.md](profile/README.md)).

## Dev stats pipeline

The Engineering section of the org profile is generated by
[`stats/collect_stats.py`](stats/collect_stats.py) (data) and
[`stats/render_charts.py`](stats/render_charts.py) (SVGs), driven daily at
03:00 UTC by the [`update-dev-stats`](.github/workflows/update-dev-stats.yml)
workflow.

- **Data** lives in [`data/`](data/) as CSVs — aggregate numbers only; repo
  names are never published (repo sizes are anonymized ranks).
- **Charts** are committed to `profile/assets/stats/` as dark + light SVGs
  and picked via `<picture>` / `prefers-color-scheme`.
- Every run recomputes the full history from fresh clones (fast — the whole
  backfill takes well under a minute), so the pipeline is idempotent and has
  no append-state to corrupt. Because `main` is PR-protected, the workflow
  force-updates `chore/dev-stats`, opens/updates a PR, and squash-merges it
  (0 approvals required on this repo).

### Method

- **Lines of code** — raw newline count of every tracked non-binary blob on
  the default branch, sampled at the last commit of each UTC day.
  Vendored code (`node_modules/`, `vendor/`, virtualenvs) and git submodules
  are excluded.
- **Additions/deletions & focus** — `git log --numstat` on default branches,
  merge commits excluded. Focus buckets by extension: TypeScript/JS/CSS/HTML
  = frontend; Rust/Python/Solidity/SQL = backend; everything else = infra & docs.
- **Repos over time** — cumulative count by repository creation date.
- **PRs merged** — via the GitHub API, bucketed by ISO week.

### Required secret: `ORG_STATS_TOKEN`

The workflow clones every (private) org repo **and** opens/merges the daily
stats PR (org policy blocks `GITHUB_TOKEN` from creating PRs), so it needs a
fine-grained org PAT stored as an Actions secret on this repo:

1. GitHub → Settings → Developer settings → Fine-grained tokens → *Generate
   new token* (or edit the existing one).
2. **Resource owner:** `BasisTradingDotNet` · **Repository access:** All
   repositories.
3. **Repository permissions:**
   - Contents: **Read and write** (needed to merge the stats PR into this repo)
   - Metadata: *Read-only*
   - Pull requests: **Read and write** (create + squash-merge `chore/dev-stats`)
4. Set a long expiry (or calendar a rotation) and generate.
5. In this repo: Settings → Secrets and variables → Actions →
   `ORG_STATS_TOKEN` → update the value.

Branch push of `chore/dev-stats` still uses the default `GITHUB_TOKEN`; only
PR create/merge uses the PAT.

### Run locally

```bash
pip install -r stats/requirements.txt
mkdir -p /tmp/org-repos && cd /tmp/org-repos
gh repo list BasisTradingDotNet --limit 200 --json name --jq '.[].name' |
  xargs -I{} git clone git@github.com:BasisTradingDotNet/{}.git
cd -
python stats/collect_stats.py --repos-dir /tmp/org-repos --out-dir data
python stats/render_charts.py --data-dir data --out-dir profile/assets/stats
# PNG previews for eyeballing: add --ext png and a different --out-dir
```
